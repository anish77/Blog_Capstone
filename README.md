# Flask Blog Project

A simple blog website built with **Flask** and **Python**.

The application fetches blog post data from an external API, converts each post into a `Post` object, displays all posts on the home page, and allows users to open individual blog posts on separate pages.

## Features

- Fetches blog posts from an external API
- Uses a custom `Post` class to represent each blog post
- Displays all posts on the home page
- Uses dynamic Flask routes for individual posts
- Uses Jinja templates to render HTML pages
- Built with Flask and Requests
